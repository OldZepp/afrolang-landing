## О проекте

**AfroLang** — концепт продающего одностраничного сайта для преподавателя африканских языков Камарии Нгози. Предназначен для русскоязычных специалистов, работающих в Африке, путешественников и интересующихся языками континента.

**Цель:** представить направления обучения и привести посетителя к форме записи на пробный урок.

> **Статус:** демонстрационный проект для портфолио, не действующий сервис записи на обучение.

## Возможности

- Адаптивный Hero-блок с главным изображением и небольшим круглым портретом эксперта справа снизу.
- Карточки пяти языков: арабский, суахили, хауса, йоруба, амхарский.
- Разделы о практической пользе языков, гарантии, эксперте и демонстрационных отзывах.
- Орнаменты, плавные анимации при прокрутке, hover-эффекты, лёгкий параллакс.
- Мобильное меню и плавающая кнопка записи.
- Форма-заглушка с автоподстановкой выбранного языка.
- **Основные изображения размещаются локально в `assets/img/`, а не загружаются с Imgur** после выполнения настройки ниже.

> В исходном пакете фотографии не вложены: перед публикацией локальной версии их нужно загрузить. Это делает скрипт, который проверяет файлы и **только после успешной загрузки всех шести** меняет пути в HTML. Если загрузка не удалась, сайт остаётся со старыми ссылками, чтобы ничего не сломать.

## Перенос изображений с Imgur в репозиторий

1. Распакуйте ZIP-пакет целиком на компьютер.
2. В Windows дважды щёлкните `download-images-windows.bat` (нужен установленный Python 3). Или выполните `python setup_images.py` в терминале.
3. Дождитесь надписи **«ГОТОВО! Все изображения локальные, index.html обновлён.»**
4. Убедитесь, что в папке `assets/img/` есть шесть настоящих изображений.
5. На GitHub в репозитории `OldZepp/afrolang-landing` замените корневой `index.html`, `README.md` и добавьте папку `assets/img/` с изображениями. Скрипты можно также добавить в репозиторий, но для работы сайта они не нужны.
6. После публикации проверьте адрес: https://oldzepp.github.io/afrolang-landing/ .

Если Imgur недоступен: сохраните **оригинальные** шесть изображений вручную с исходных адресов в `assets/img/` под указанными именами; повторный запуск скрипта проверит их и обновит HTML. При этом нельзя заменять JPEG файлом другого формата без изменения имени/скрипта.

## Локальный запуск

Откройте `index.html` в браузере. Сервер и сборщик не требуются. После переноса изображений локальный показ фотографий не зависит от Imgur; для Google Fonts и Font Awesome подключение к интернету по-прежнему может понадобиться.

## Ограничения демонстрации

- Форма **не отправляет** заявки на сервер; только показывает уведомление и выводит введённые значения в консоль.
- Имена учеников и отзывы вымышлены и **не являются реальными отзывами**.
- Email — демонстрационный адрес.
- Обещания гарантированного результата и сведения о преподавателе взяты из исходного задания и требуют подтверждения перед коммерческим использованием.
- Фотографии и графические материалы требуют проверки прав использования перед коммерческой публикацией.
