# AfroLang — landing page demo

Адаптивный демонстрационный лендинг обучения африканским языкам.

## Стек
HTML5, CSS3, vanilla JavaScript, Google Fonts, Font Awesome.

## Запуск
Откройте `index.html` в браузере. Для GitHub Pages опубликуйте корень ветки `main` (Settings → Pages → Deploy from a branch → main → /(root)).

## Важно перед публикацией
- Отзывы, имена учеников и контактный email демонстрационные и не должны подаваться как подтверждённые настоящие.
- Заявка не отправляется на сервер, а только показывает уведомление и пишет содержимое в консоль браузера.
- Формулировку гарантии, биографические сведения и использование портретов следует согласовать с правообладателем/клиентом.
- Изображения загружаются с внешнего Imgur, шрифты и иконки — с CDN. Их доступность зависит от внешних серверов.
