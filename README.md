AfroLang — концепт продающего одностраничного сайта для преподавателя африканских языков Камарии Нгози. Сайт адресован русскоязычным специалистам, которые работают или планируют работать в Африке, а также путешественникам и всем, кто интересуется языками континента.

Задача: наглядно представить направления обучения, преимущества индивидуальных занятий и привести посетителя к форме записи на пробный урок.
Статус: демонстрационный проект для портфолио. Это не действующий сервис записи на обучение.

Что реализовано
- Выразительный первый экран с фотографиями, градиентной типографикой и кнопками перехода к разделам.
- Адаптивная вёрстка для смартфонов, планшетов и десктопов.
- Пять карточек направлений: арабский, суахили, хауса, йоруба, амхарский.
- Блоки о практическом применении языков, методике и преподавателе.
- Декоративные орнаменты, анимации появления при прокрутке, hover-эффекты и лёгкий параллакс.
- Мобильная навигация и плавающая кнопка записи.
- Демонстрационная форма: имя, контакт и выбор языка. Выбор языка в карточке автоматически подставляется в форму.

В проекте нет сборщика и JS-фреймворков: весь сайт находится в одном index.html со встроенными стилями и скриптами.
Запуск локально
1. Скачайте репозиторий: Code → Download ZIP, затем распакуйте архив.
2. Откройте файл index.html двойным щелчком или через браузер.
3. Для изменения дизайна отредактируйте CSS внутри <style>, для поведения — JavaScript внутри <script>.
Демо и ограничения
- Форма не отправляет заявки: по нажатию появляется уведомление, а данные выводятся в консоль браузера. Для реальной работы потребуется серверная обработка, защита персональных данных и политика конфиденциальности.
- Отзывы и имена учеников вымышлены: представлены исключительно как пример оформления. Они не подтверждают реальные результаты обучения.
- Контактный адрес демонстрационный.
- Гарантия результата и биографические сведения взяты из исходного учебного задания и требуют подтверждения перед коммерческим использованием.
- Фотографии загружаются по внешним ссылкам Imgur, шрифты и иконки — из внешних CDN. Доступность этих ресурсов не гарантируется.
